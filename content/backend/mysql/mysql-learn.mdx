# MySQL数据库常用数据类型

**数值类型**

|类型|大小|用途
|:--------|:--------|:--------|
|INT|4 Bytes|大整数值
|FLOAT|4 Bytes|单精度浮点数值|
|DOUBLE|8 Bytes|双精度浮点数值

**字符串类型**

|类型|大小|用途
|:--------|:--------|:--------|
|CHAR|0-255 bytes|定长字符串|
|VARCHAR|0-65535 bytes|变长字符串|
|TEXT|0-65 535 bytes|长文本数据|

>注意：char(n) 和 varchar(n) 中括号中 n 代表字符的个数，并不代表字节个数，比如 CHAR(30) 就可以存储 30 个字符。

**日期和时间类型**

|类型	|大小	|格式	|用途
|:--------|:--------|:--------|:--------|
|DATE|3 bytes|YYYY-MM-DD|日期值|
|TIME|3 bytes|HH:MM:SS|时间值或持续时间|
|YEAR|1 bytes|YYYY|年份值|
|DATETIME|8 bytes|YYYY-MM-DD hh:mm:ss|混合日期和时间值|
|TIMESTAMP|4 bytes|YYYY-MM-DD hh:mm:ss|混合日期和时间值，时间戳|

**MySQL 中没有独立的布尔数据类型**

BOOLEAN 和 BOOL 只是 TINYINT(1) 的别名，底层用整数存储：

|写法|	实际类型|	取值
|:--------|:--------|:--------|
|BOOLEAN|	TINYINT(1)|	0 = FALSE，非 0 = TRUE
|BOOL|	TINYINT(1)|	同上

```SQL
CREATE TABLE users (
    id INT PRIMARY KEY,
    is_active BOOLEAN DEFAULT TRUE,
    is_deleted BOOL DEFAULT FALSE
);
-- 插入时可以用 TRUE / FALSE（分别等价于 1 / 0）

INSERT INTO users (id, is_active, is_deleted)
VALUES (1, TRUE, FALSE);

-- 等价于
INSERT INTO users (id, is_active, is_deleted)
VALUES (1, 1, 0);

-- 查询
SELECT * FROM users WHERE is_active = TRUE;
SELECT * FROM users WHERE is_active;        -- 非 0 即为真
SELECT * FROM users WHERE NOT is_deleted;
```


# 创建数据库

>SQL 语句的大小写其实没有强制规定，MySQL 对关键字大小写不敏感，但实际开发中推荐关键字用大写，表名、字段名、库名用小写。

**基础语法**
``` CREATE DATABASE 数据库名 ```

**指定字符集**

``` CREATE DATABASE 数据库名 CHAR SET 'utf8mb4' ```


```SQL
CREATE DATABASE db_study CHAR SET 'utf8mb4'
```
>注意：如果数据库已经存在，执行 CREATE DATABASE 会错误。可以在 CREATE DATABASE 语句中添加 IF NOT EXISTS 子句

```SQL
CREATE DATABASE IF NOT EXISTS db_study CHAR SET 'utf8mb4'

-- IF NOT EXISTS 的作用就是：如果数据库不存在就创建，如果已经存在就什么都不做，只给个警告。
```

# 选择数据库
在 MySQL 中，要选择要使用的数据库，可以使用 USE 语句：``` USE 数据库名字 ```，选择数据库后，后续 SQL 查询和操作在指定的数据库上执行。

# 删除数据库
可以使用drop 命令删除数据库
```text
DROP DATABASE <database_name>;        -- 直接删除数据库，不检查是否存在
或
DROP DATABASE [IF EXISTS] <database_name>;
```
- IF EXISTS 是一个可选的子句，表示如果数据库存在才执行删除操作，避免因为数据库不存在而引发错误。
- database_name 是你要删除的数据库的名称。

# 创建数据表

创建 MySQL 数据表需要以下信息：
- 表名
- 表字段名
- 定义每个表字段的数据类型

```SQL
CREATE TABLE table_name(
    column1 datatype,
    column2 datatype,
)
```

- table_name 是你要创建的表的名称。
- column1, column2, ... 是表中的列名。
- datatype 是每个列的数据类型。

```SQL
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    birthdate DATE,
    is_active BOOLEAN DEFAULT TRUE
);
```
- id: 用户 id，整数类型，自增长，作为主键。
- username: 用户名，变长字符串，不允许为空。
- email: 用户邮箱，变长字符串，不允许为空。
- birthdate: 用户的生日，日期类型。
- is_active: 用户是否已经激活，布尔类型，默认值为 true。

# MySQL数据库支持的约束条件

## PRIMARY KEY（主键约束）
每个表都需要有主键，并且主键唯一、不能为null、不能重复
```SQL
CREATE TABLE t_user (
    id INT PRIMARY KEY,
    name VARCHAR(20)
);
```

## AUTO_INCREMENT（自增约束）
通常配合主键使用，插入时不指定值，自动递增。
```SQL
CREATE TABLE t_user (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20)
);

-- 插入 name 时不用管 id，它会自动 1、2、3……递增
```

## DEFAULT（默认值约束）
不填该字段时，自动使用默认值。
```SQL
CREATE TABLE t_user (
    id INT,
    age INT DEFAULT 18,
);

-- 插入时不写 age，它会自动变成 18。
```

## NOT NULL（非空约束）
字段值不能为空。
```SQL
CREATE TABLE t_user (
    id INT NOT NULL,
    name VARCHAR(20) NOT NULL
);

-- 插入数据时，name 必须给值，否则报错。
```

## UNIQUE（唯一约束）
该列的值不能重复，但允许为 NULL（且多个 NULL 不算重复）。
```SQL
CREATE TABLE t_user (
    id INT PRIMARY KEY,
    phone VARCHAR(20) UNIQUE,
    email VARCHAR(50) UNIQUE
);
```

## FOREIGN KEY（外键约束）
让两张表建立关联，保证子表的值必须在主表中存在。
```SQL
CREATE TABLE t_class (
    id INT PRIMARY KEY,
    class_name VARCHAR(20)
);

CREATE TABLE t_student (
    id INT PRIMARY KEY,
    name VARCHAR(20),
    class_id INT,
    FOREIGN KEY (class_id) REFERENCES t_class(id)
);

-- 这样 t_student.class_id 必须是 t_class 里已有的 id，否则插不进去。
```

# 操作数据

## 增（INSERT INTO）
向MySQL数据表插入数据通用的 INSERT INTO SQL语法
```text
INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);
```
参数说明：
- table_name 是你要插入数据的表的名称。
- column1, column2, column3, ... 是表中的列名。
- value1, value2, value3, ... 是要插入的具体数值。
```SQL
INSERT INTO users (username, email, birthdate, is_active)
VALUES ('test', 'test@runoob.com', '1990-01-01', true);
```
如果要插入多行数据，可以在 VALUES 子句中指定多组数值：
```SQL
INSERT INTO users (username, email, birthdate, is_active)
VALUES
    ('test1', 'test1@runoob.com', '1985-07-10', true),
    ('test2', 'test2@runoob.com', '1988-11-25', false),
    ('test3', 'test3@runoob.com', '1993-05-03', true);
```
## 查（SELECT）
MySQL 数据库使用 SELECT 语句来查询数据
```text
SELECT column1, column2, ...
FROM table_name
[WHERE condition]
[ORDER BY column_name [ASC | DESC]]
[LIMIT number];
```
- column1, column2, ... 是你想要选择的列的名称，如果使用 * 表示选择所有列。
- table_name 是你要从中查询数据的表的名称。
- WHERE condition 是一个可选的子句，用于指定过滤条件，只返回符合条件的行。
- ORDER BY column_name [ASC | DESC] 是一个可选的子句，用于指定结果集的排序顺序，默认是升序（ASC）。
- LIMIT number 是一个可选的子句，用于限制返回的行数。

```SQL
-- 选择所有列的所有行
SELECT * FROM users;

-- 选择特定列的所有行
SELECT username, email FROM users;

-- 添加 WHERE 子句，选择满足条件的行
SELECT * FROM users WHERE is_active = TRUE;

-- 添加 ORDER BY 子句，按照某列的升序排序
SELECT * FROM users ORDER BY birthdate;

-- 添加 ORDER BY 子句，按照某列的降序排序
SELECT * FROM users ORDER BY birthdate DESC;

-- 添加 LIMIT 子句，限制返回的行数
SELECT * FROM users LIMIT 10;
-- 语法：`LIMIT offset, size`
-- offset：偏移量 = (页码 - 1)* 每页条数
-- ize：每页多少条

-- 总数
select count(*) as '总数' from users;

-- 使用 AND 运算符和通配符
SELECT * FROM users WHERE username LIKE 'j%' AND is_active = TRUE;

-- 使用 OR 运算符
SELECT * FROM users WHERE is_active = TRUE OR birthdate < '1990-01-01';

-- 使用 IN 子句
SELECT * FROM users WHERE birthdate IN ('1990-01-01', '1992-03-15', '1993-05-03');
```

## 改 （UPDATE）

如果要修改或更新 MySQL 中的数据，可以使用 UPDATE 命令来操作。
```test
UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;
```
- table_name 是你要更新数据的表的名称。
- column1, column2, ... 是你要更新的列的名称。
- value1, value2, ... 是新的值，用于替换旧的值。
- WHERE condition 是一个可选的子句，用于指定更新的行。如果省略 WHERE 子句，将更新表中的所有行。

```SQL
UPDATE orders
SET status = 'Shipped', ship_date = '2023-03-01'
WHERE id = 1001;
```

## 删（DELETE FROM）
可以使用 DELETE FROM 命令来删除 MySQL 数据表中的记录。
```text
DELETE FROM table_name
WHERE condition;
```
- table_name 是你要删除数据的表的名称。
- WHERE condition 是一个可选的子句，用于指定删除的行。如果省略 WHERE 子句，将删除表中的所有行。
- 如果没有指定 WHERE 子句，MySQL 表中的所有记录将被删除。
- 你可以在 WHERE 子句中指定任何条件
- 您可以在单个表中一次性删除记录。

```SQL
--  删除符合条件的行
DELETE FROM students WHERE graduation_year = 2021;

-- 删除所有行
DELETE FROM orders;
```

# 常用条件
```SQL
-- 等于
SELECT * FROM users WHERE username = 'test';

-- 不等于
SELECT * FROM users WHERE username != 'runoob';

-- 大于
SELECT * FROM products WHERE price > 50.00;

-- 小于
SELECT * FROM orders WHERE order_date < '2023-01-01';

--大于等于
SELECT * FROM employees WHERE salary >= 50000;

--小于等于
SELECT * FROM students WHERE age <= 21;

-- 组合条件（AND、OR）
SELECT * FROM products WHERE category = 'Electronics' AND price > 100.00;

SELECT * FROM orders WHERE order_date >= '2023-01-01' OR total_amount > 1000.00;

-- 模糊匹配条件（LIKE）: 用来做模糊匹配
SELECT * FROM customers WHERE first_name LIKE 'J%';

--  IN条件: 判断字段值是否属于给定的几个值之一
SELECT * FROM countries WHERE country_code IN ('US', 'CA', 'MX');

-- NOT 条件: 取反
SELECT * FROM products WHERE NOT category = 'Clothing';

-- BETWEEN 条件: 判断字段值是否在闭区间 [最小值, 最大值] 内，包含两端
SELECT * FROM orders WHERE order_date BETWEEN '2023-01-01' AND '2023-12-31';

-- iS NULL 条件: 判断字段值是否为 NULL。
SELECT * FROM employees WHERE department IS NULL;

--  IS NOT NULL 条件: 判断字段值是否不为 NULL。
SELECT * FROM customers WHERE email IS NOT NULL;

```

# LIKE
LIKE 是 SQL 里用来做模糊匹配的关键字，通常配合通配符使用，放在 WHERE 子句里

|通配符|	含义|	示例|
|:--------|:--------|:--------|
|%|	匹配任意个字符（包括 0 个）|	'张%' 匹配“张”、“张三”、“张abc”
|_|	匹配恰好一个字符|	'张_' 匹配“张三”、“张四”，但不匹配“张”或“张三丰”

|写法|	含义
|:--------|:--------|
|LIKE '张%'|	以“张”开头
|LIKE '%三'|	以“三”结尾
|LIKE '%三%'|	包含“三”
|LIKE '张_'|	“张”开头且后面恰好一个字符
|LIKE '_三%'|	第二个字是“三”
|NOT LIKE '张%'|	不以“张”开头

>LIKE 以 % 开头（比如 '%三'、'%三%'）时，无法使用索引，全表扫描，数据量大时很慢。如果能确定前缀，尽量写成 '张%' 这种形式，可以用上索引

# ORDER BY 排序
如果需要对读取的数据进行排序，就可以使用 MySQL 的 ORDER BY 子句来设定想按哪个字段哪种方式来进行排序，再返回搜索结果。

MySQL ORDER BY(排序) 语句可以按照一个或多个列的值进行升序（ASC）或降序（DESC）排序。

```text
SELECT column1, column2, ...
FROM table_name
ORDER BY column1 [ASC | DESC], column2 [ASC | DESC], ...;
```
- column1, column2, ... 是你要选择的列的名称，如果使用 * 表示选择所有列。
- table_name 是你要从中查询数据的表的名称。
- ORDER BY column1 [ASC | DESC], column2 [ASC | DESC], ... 是用于指定排序顺序的子句。ASC 表示升序（默认），DESC 表示降序。
- 可以使用任何字段来作为排序的条件，从而返回排序后的查询结果。
- 可以设定多个字段来排序。
- 可以使用 ASC 或 DESC 关键字来设置查询结果是按升序或降序排列。 默认情况下，它是按升序排列。
- 可以添加 WHERE...LIKE 子句来设置条件。

```SQL
SELECT * FROM student ORDER BY age DESC;
-- 按照年龄倒序排列
```

# GROUP BY 分组
GROUP BY 语句根据一个或多个列对结果集进行分组。
```text
SELECT column1, aggregate_function(column2)
FROM table_name
WHERE condition
GROUP BY column1;
```
- column1：指定分组的列。
- aggregate_function(column2)：对分组后的每个组执行的聚合函数。
- table_name：要查询的表名。
- condition：可选，用于筛选结果的条件。

**练习**
```SQL
-- SQL分组练习

-- 选择数据库
USE db_study;

-- 创建数据表
CREATE TABLE score(
	id INT PRIMARY KEY AUTO_INCREMENT,
    student_name VARCHAR(50) NOT NULL,
    subject VARCHAR(50) NOT NULL,
    score INT NOT NULL
);

-- 插入数据
INSERT INTO score(student_name,subject,score) VALUES
('张三', '语文', 85),
('张三', '数学', 92),
('张三', '英语', 78),
('李四', '语文', 90),
('李四', '数学', 88),
('李四', '英语', 95),
('王五', '语文', 70),
('王五', '数学', 60),
('王五', '英语', 55),
('赵六', '语文', 88),
('赵六', '数学', 76),
('赵六', '英语', 82);

-- 查看所有数据
SELECT * FROM score;

-- 使用分组查看每个学生的总分
SELECT student_name, SUM(score) AS 总分 FROM score GROUP BY student_name;

-- 统计每个学生的总分、平均分、最高分、考试科目数
SELECT student_name,
SUM(score) AS 总分,
AVG(score) AS 平均分,
MAX(score) AS 最高分,
MIN(score) AS 最低分,
COUNT(subject)  AS 科目
FROM score 
GROUP BY student_name;

-- 每科平均分，最高分、最低分
SELECT subject,
AVG(score) AS 平均分,
MAX(score) AS 最高分,
MIN(score) AS 最低分
FROM score
GROUP BY subject;

-- 每个学生每科的成绩
SELECT student_name, subject, score
FROM score
GROUP BY student_name, subject, score;

-- 只看>=60的成绩，在统计每个学生的总分
SELECT student_name, SUM(score) AS 总分
FROM score
WHERE score>=60
GROUP BY student_name;

-- 找出总分超过250的学生
SELECT student_name, SUM(score) AS 总分
FROM score
GROUP BY student_name
HAVING SUM(score)>250;

-- 只统计及格的科目，找出及格科目总分超过 250 的学生
SELECT student_name, SUM(score) AS 总分
FROM score
WHERE score>=60
GROUP BY student_name
HAVING SUM(score)>250;
```

>WHERE 管分组前，HAVING 管分组后；聚合函数只能放 HAVING。

**执行顺序**

```SQL
SELECT   student_name, SUM(score)    -- ⑤ 最后选出要显示的列
FROM     score                       -- ① 先确定表
WHERE    score >= 60                 -- ② 分组前过滤
GROUP BY student_name                -- ③ 分组
HAVING   SUM(score) > 250            -- ④ 分组后过滤
ORDER BY SUM(score) DESC;            -- ⑥ 排序
```
>注意：
- `select` 后面非聚合字段，必须出现在 `GROUP BY` 里（only_full_group_by 模式，新版 MySQL 默认开启）
- 分组之后过滤条件用 `HAVING`，不能用 WHERE；WHERE 是分组前过滤

## 子查询
子查询 = 写在括号里的一条 SELECT 语句，它先执行，把结果交给外层查询用。
```SQL
SELECT ... FROM 表 WHERE 字段 运算符 (SELECT ... FROM ...);
                              ↑ 这就是子查询
```
```SQL
-- 查询高于全体平均分的成绩
SELECT student_name, subject, score
FROM score
WHERE score>(SELECT AVG(score) FROM score);
```

- student：学生基本信息（姓名、班级）

- score：谁 选了 哪门课 考了多少分

成绩表只存 id，不存姓名和课程名，要用时再"连"起来查。

### INNER JOIN 内链接
**基础语法**
```text
SELECT 字段
FROM 表A
INNER JOIN 表B
NO 表A.关联字段 = 表B.关联字段
WHERE 筛选条件
```
```SQL
-- 查询每个学生的成绩
SELECT name, score
FROM student st
INNER JOIN score sc ON st.id=sc.student_id;

-- 三表联查——查出"谁 考了 哪门课 多少分"
SELECT st.name,co.course_name,sc.score
FROM score sc
INNER JOIN student st ON sc.student_id = st.id
INNER JOIN course co ON sc.course_id = co.id;

-- 每个学生的总分，且只显示总分 ≥ 250 的。
SELECT st.name, SUM(sc.score) AS 总分
FROM student st
INNER JOIN score sc ON st.id=sc.student_id
GROUP BY st.name
HAVING SUM(sc.score)>250;
```
### LEFT JOIN（左外连接）
左表所有行都保留，右表匹配不上的用 NULL 填充。

```SQL
-- 查询所有学生（含没选课的），显示其成绩
SELECT st.name, sc.score
FROM student st
LEFT JOIN score sc ON st.id = sc.student_id;

-- 结果中 孙七 会出现，score 列是 NULL

-- 找出"没选任何课"的学生
SELECT st.name, sc.student_id
FROM student st
LEFT JOIN score sc ON st.id = sc.student_id
WHERE sc.student_id IS NULL;

-- 统计每个学生选了几门课（含 0 门）
SELECT st.name, COUNT(sc.id) AS 选课数
FROM student st
LEFT JOIN score sc ON st.id = sc.student_id
GROUP BY st.name;
```

### RIGHT JOIN（右外连接）
保留右表全部，和 LEFT JOIN 对称。
```SQL
-- 查询所有课程，显示选课情况
SELECT co.course_name, st.name
FROM course co
RIGHT JOIN student st ON co.credit = st.id
WHERE co.course_name IS NOT NULL; -- 孙七没选课
```

### 两边都保留
MySQL 不支持 FULL OUTER JOIN。要"两边都保留"，用 LEFT JOIN + UNION + RIGHT JOIN 模拟：
```SQL
SELECT s.name, sc.score
FROM student s LEFT JOIN score sc ON s.id = sc.student_id
UNION
SELECT s.name, sc.score
FROM student s RIGHT JOIN score sc ON s.id = sc.student_id;
```

```text
SELECT ... FROM 表B;
```

**UNION vs UNION ALL**

|写法|	行为
|:-------|:-------|
|UNION|	去重（合并后删掉重复行）
|UNION ALL|	不去重（原样叠加，保留所有行）

# 索引
MySQL 索引是一种数据结构，用于加快数据库查询的速度和性能，命中索引才能提高查询效率，查询时需要使用上索引，索引才能生效。

**注意**
- 占用额外磁盘空间
- 增删改数据时要同步维护索引，降低写入速度

所以索引不是越多越好，而是为高频、高选择性的查询条件建立。

## 索引分类
### 主键索引 PRIMARY KEY
> 唯一、非空，一张表只能一个、聚簇索引

```SQL
CREATE TABLE orders (
  id INT PRIMARY KEY AUTO_INCREMENT
);
```

### 唯一索引 UNIQUE
>索引字段的值不能重复，可以为 NULL（允许多个 null）

```SQL
-- 建表时
order_no VARCHAR(32) NOT NULL UNIQUE
-- 单独创建
CREATE UNIQUE INDEX uk_orders_order_no ON orders(order_no);
```

### 普通索引 INDEX（最常用）
>只加速查询，不限制唯一

```SQL
CREATE INDEX idx_orders_user_id ON orders(user_id);
```

### 联合索引（复合索引）
>多个字段一起建索引，**最左前缀原则**

```SQL
CREATE INDEX idx_user_status_amount ON orders(user_id, status, amount);
```
> 注意：联合索引的最左原则，`where status=?`、`where amount=?`、`where status=? and amount=?`都不会生效。

## 索引创建、查看、删除语句
```SQL
-- 创建普通索引
CREATE INDEX idx_orders_user_id ON orders(user_id);

-- 创建联合索引
CREATE INDEX idx_orders_user_status ON orders(user_id, status);

-- 查看表索引
SHOW INDEX FROM orders;

-- 删除索引
DROP INDEX idx_orders_user_id ON orders;
```

## 验证索引有没有生效：EXPLAIN
```SQL
EXPLAIN SELECT * FROM orders WHERE user_id = 1;
```
重点看字段：

1. `type`：访问类型（优先级从好到坏）
`system > const > eq_ref > ref > range > index > ALL`
`ALL` = 全表扫描，没用到索引，需要优化
2. `key`：实际使用到的索引名，NULL = 没走索引
3. `rows`：预估扫描行数，越小越好
4. `Extra`：
    - `Using index`：覆盖索引 ✅
    - `Using where`：拿到索引后还要过滤
    - `Using temporary`：用到临时表（group by 常见，性能差）
    - `Using filesort`：文件排序，order by 没走索引，性能差

## 索引失效场景
基于索引 `idx(user_id, status, amount)`
1. **like 以 % 开头** `where username like '%张三'` → 索引失效；`like '张三%'` 可以走
2. **索引列参与运算 / 函数**
```SQL
-- ❌ 失效
WHERE user_id + 1 = 1
WHERE DATE(create_time) = '2026-11-10'
-- ✅ 改写成：
WHERE create_time >= '2026-11-10 00:00:00' AND create_time < '2026-11-11 00:00:00'
```
3. **隐式类型转换**（坑最多！）
`order_no` 是字符串，你传数字：`WHERE order_no = 123` → 字段被转成数字，索引失效
4. **or 两边有一个字段没有索引**，整个索引失效
补救：or 两边字段都单独建索引
5. **联合索引违反最左前缀**
6. **范围条件（> < between）后面的字段索引失**
7. `where user_id=1 and status>0 and amount=99` → amount 不走索引
8. 优化器判断：索引还不如全表快（比如符合条件数据占表超过 20%~30%，mysql 放弃索引）

# SQL练习
```SQL
-- 电商订单简易系统

-- 创建数据库
create database if not exists db_dianshang char set 'utf8mb4';

-- 选择创建的数据库
use db_dianshang;

-- 创建用户表
create table user(
	id int primary key auto_increment comment '用户主键', 
    username varchar(50) not null comment '用户名字',
    phone varchar(11) not null comment '手机号',
    age tinyint comment '年龄', 
    create_time datetime default current_timestamp comment '创建时间'
) engine=InnoDB default charset=utf8mb4 comment '用户表';
-- comment 是注释
-- init 大整数
-- tinyint 小整数
-- engine=InnoDB使用 InnoDB 存储引擎（支持事务、行级锁、外键）
-- default charset=utf8mb4 默认字符集为 utf8mb4，支持完整的 Unicode（含 emoji、生僻字）

-- 创建订单表
create table order_info(
	id int primary key auto_increment comment '订单主键',
    order_no varchar(32) not null comment '订单编号',
    user_id int not null comment '用户id',
    amount decimal(10,2) not null comment '订单金额', 
    status tinyint default 1 comment '订单状态 1待支付 2已支付 3已取消',
    create_time datetime default current_timestamp comment '下单时间',
    -- 外键
    foreign key(user_id) references user(id)
)engine=InnoDB default charset=utf8mb4 comment '订单表';
-- decimal(10,2) 总位数 10 位，其中小数 2 位
-- foreign key (user_id) 在当前表上声明一个外键，作用在 user_id 列
-- references user(id) 引用 user 表的 id 列（被引用列必须是主键或唯一键）

-- 新增用户
INSERT INTO `user`(username, phone, age) VALUES
('张三','13800138001',22),
('李四','13800138002',25),
('王五','13800138003',30),
('赵六','13800138004',28);

-- 新增订单
INSERT INTO order_info(order_no,user_id,amount,status) VALUES
('ORD20261107001',1,99.00,2),
('ORD20261107002',1,199.00,1),
('ORD20261107003',2,299.00,2),
('ORD20261107004',3,59.00,3),
('ORD20261107005',3,399.00,2),
('ORD20261107006',3,129.00,1);

-- 基础查询

-- 查询全部用户
select * from user;

-- 查询全部订单
select *from order_info;

-- 条件查询：年龄大于24的用户
select *from user where age>24;
select id, username as '名字', age as '年龄' from user where age>24;

-- 查询已支付的订单
select * from order_info where status = 2;

-- 修改id=1用户的年龄
update user set age = 23 where id=1;

-- 修改订单状态：把订单号 ORD20261107002 修改为已支付(2)
UPDATE order_info SET status=2 WHERE order_no='ORD20261107002';

-- 排序 升序 asc, 降序 desc 
select *from user order by age desc;

-- 分页查询
select *from user limit 0, 2;
-- 语法：`LIMIT offset, size`
-- offset：偏移量 = (页码 - 1)* 每页条数
-- ize：每页多少条

-- 总数
select count(*) as '总数' from user;

-- 多表联查

-- INNER JOIN 内连接：只查出两边匹配上的数据（有订单的用户）
select
u.id user_id,
u.username user_name,
o.id order_id,
o.order_no,
o.amount,
o.status
from user u
inner join order_info o on u.id = o.user_id;

-- LEFT JOIN 左连接：左边表全部保留，右边没有匹配则为 NULL（重点！）
SELECT
  u.id user_id,
  u.username,
  o.order_no,
  o.amount
FROM `user` u
LEFT JOIN order_info o ON u.id = o.user_id;

-- 索引
-- WHERE 条件、JOIN 关联字段、ORDER BY、GROUP BY 的字段适合建索引；主键自带主键索引。

-- 创建单列索引
create index idx_order_userid ON order_info(user_id);

-- 订单号经常按 order_no 精确查找，建索引
create index idx_order_no on order_info(order_no);

-- 联合索引：经常 status + create_time 一起筛选排序
create index idx_status_createtime on order_info(status, create_time);

-- 查看索引 
show index from order_info;

-- 验证索引是否生效：EXPLAIN
EXPLAIN
SELECT * FROM order_info WHERE user_id=1;
-- `type`：ref/range 比较好；ALL 代表全表扫描（没走索引）
-- `key`：显示用到的索引名字，代表索引生效

-- 分组统计：每个用户有多少订单
SELECT user_id, COUNT(*) AS order_count, SUM(amount) AS sum_amount
FROM order_info
GROUP BY user_id;

-- 分组 + having 过滤聚合结果（having 是过滤分组后，where是分组前）
SELECT user_id, COUNT(*) AS order_count
FROM order_info
GROUP BY user_id
HAVING COUNT(*) >=2;

-- 模糊查询 
INSERT INTO `user`(username, phone, age) VALUES
('张飞','13800138005',18 );
-- 1. 查询用户名【以张开头】：张%
select *from user where username like '张%';

-- 2. 查询用户名【以三结尾】：%三
SELECT * FROM `user` WHERE username LIKE '%三';
INSERT INTO `user`(username, phone, age) VALUES
('张小飞','13800138005',18 );

-- 3. 查询用户名【包含“小”字】，最常用模糊搜索
SELECT * FROM `user` WHERE username LIKE '%小%';

-- 名字第三个字是华：__飞
SELECT * FROM `user` WHERE username LIKE '__飞';

-- 分组 group by
-- GROUP BY 按照指定字段分组，相同值的合并成一组，通常配合聚合函数使用：COUNT、SUM、MAX、MIN、AVG
-- 1. `select` 后面非聚合字段，必须出现在 GROUP BY 里（only_full_group_by 模式，新版 MySQL 默认开启）
-- 2. 分组之后过滤条件用 `HAVING`，不能用 WHERE；WHERE 是分组前过滤

select
  user_id,
  count(*) as order_count,
  sum(amount) as total_money,
  avg(amount) as avg_money,
  max(amount) as max_money
from order_info
group by user_id;

select
  u.id,
  u.username,
  count(o.id) as order_num,
  sum(o.amount) as sum_amount
from `user` u
left join order_info o on u.id = o.user_id
group by u.id, u.username
having sum(o.amount) > 200;

-- 注意：only_full_group_by MySQL5.7+ 默认开启，select 里不能随便写不在 group by 里、又不是聚合的字段
-- `COUNT(*)` vs `COUNT(字段)`
-- COUNT (*)：统计分组行数，不管字段是不是 null
-- COUNT (user_id)：统计 user_id 不为 NULL 的数量，left join 场景差别很大
```
