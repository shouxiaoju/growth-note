# NumPy 简介
> NumPy是python语言的一个扩展程序库，主要用于处理大模型多维数组和矩阵，以及提高大量的数学函数来操作这些数据结构。
核心：提供高性能的多维数组对象ndarry。
优势：底层用C语言实现，比python原生列表快10-100倍。

## 创建数组

### np.array()
>从列表或者元组创建数组

``` np.array(object, dtype=None, copy=True, order=None, subok=False, ndmin=0)```

- object：数组或嵌套列表
- dtype：数组元素的数据类型
- copy：对象是否需要复制
- order：创建数组的样式
- subok：默认返回一个与基本数据类型一致的数组
- ndmin：生成数组的最小维度

```python
import numpy as np

#创建一维数组（向量）
arr1 = np.array([1,2,3])
print(arr1) # [1,2,3]

#创建二维数组（矩阵）
arr2 = np.array([[1,2,3],[4,5,6]])
print(arr2) 
'''
[
    [1,2,3],
    [4,5,6]
]
'''

#创建出的数组是可以进行遍历的
for i in arr1:
    print(i, end=" ")

print()

for i in arr2:
    for j in i:
        print(j, end=" ")
```

### np.linspace(star,stop,num)

>用于创建一个一维等差数列的数组

```np.linspace(star,stop,num=50,endpoint=True,retstep=False,dtype=None)```

- start：序列起始值
- stop：序列的终止值如果endpoint为true该值包含于数列中
- num：要生成的等长的样本数量，默认50
- endpoint：该值为true时数列中包含stop的值反之则不包含默认为True
- dtype：数据类型

```python
arr3 = np.linspace(1,10, 5, dtype=int)
print(arr3) # [ 1  3  5  7 10]
```

## NumPy 数组属性

### np.ndim
>用于获取数组的维度也就是秩
```python
import numpy as np
a=np.arange(1,11)

```
### np.shape

>表示数组的维度返回一个元组，这个元组的长度就是维度的数目，比如：一个二维数组的shape表示其行数和列数。shape元组的顺序与轴的顺序一致：第0个元素是第0轴的大小（行数），第1个元素表示第1轴的大小（列数）

```python
import numpy as np
a = np.arange(1,11)
print(a.shape) # (10,)
b=np.array([[1,2,3],[4,5,6]])
print(b.shape) # (2, 3)
```

>np.shape也可以用于调整数组的大小

```python
b=np.array([[1,2,3],[4,5,6]])
b.shape=(3,2)
print(b)
'''
[[1 2]
 [3 4]
 [5 6]]
'''
```

## 广播机制
>广播机制是对不同形状的数组进行数值计算的方式，对数组的算术运算通常在相应的元素上进行

**两个数组的形状相同**

> 如果两个数组a和b形状相同，那么a*b的结果就是a与b数组对应位相乘

```python
a=np.array([1,2,3,4])
b=np.array([10,20,30,40])
c=a*b
print(c) # [ 10  40  90 160]
```

**两个数组的形状不同时，numpy将自动触发广播机制**
```python
import numpy as np
a = np.array([2,2,2])

'''
a会扩展为
[
    [2,2,2],
    [2,2,2],
    [2,2,2],
]
'''

b = np.array([
    [10,10,10],
    [20,20,20],
    [30,30,30]
])
c=a*b
print(c) 

'''
[[20 20 20]
 [40 40 40]
 [60 60 60]]
'''
```
### 广播的规则
1. 让所有输入数组都向其中形状最长的数组看齐，形状中不足的部分都通过在前面加1补齐。
    ```python
    '''
    在读这段话时不理解什么是在前面加1，其实加1就是在维度上加1。
    比如：
        a=[[1,2,3],[4,5,6]] 是一个二维数组 ->形状是(2,3)
        b=[1,1,1] 是一个一维数组 ->形状是(3,)
        b的维度不足在其左侧加1变为：
        [[1,1,1],[1,1,1]]
        因此a+b=[[2,3,4],[5,6,7]]
    '''
    import numpy as np
    a=np.array([[1,2,3],[4,5,6]])
    b=np.array([1,1,1])
    c=a+b
    print(c) # [[2,3,4],[5,6,7]]
    ```
2. 输出数组的形状是输入数组形状的各个维度上的最大值
    - 比如上述代码输出的维度就是2
3. 如果输入数组的某个维度和输出数组的对应维度的长度相同或者其长度为1时，这个数组能够用来计算，否则报错
4. 当输入数组的某个维度的长度为1时，沿着此维度运算时都用此维度上的第一组值
    - 数组拥有相同形状
    - 当前维度的值相等
    - 当前维度的值有一个是1

### arr.ravel()
>展平数组元素，默认按行展开，order:'C'--按行、'F'--按列、'A'--原顺序、'K'--元素在内存中的出现顺序
```python
import numpy as np
a=np.arange(8).reshape(2,4)
print('原数组')
print(a)
print('\n')

print('展开的数组')
print(a.ravel()) # 默认按行展开，order:'C'--按行、'F'--按列、'A'--原顺序、'K'--元素在内存中的出现顺序
print('\n')

print('以 F 风格顺序展开的数组')
print(a.ravel(order='F'))
```
**输出结果**
```text
原数组
[[0 1 2 3]
 [4 5 6 7]]


展开的数组
[0 1 2 3 4 5 6 7]


以 F 风格顺序展开的数组
[0 4 1 5 2 6 3 7]
```
### arr.flatten()
>返回一份拷贝后的数组，对新数组进行操作不会影响原始数组
```python
import numpy as np
a=np.arange(8).reshape(2,4)
print('原数组')
print(a)
print('\n')

print('展开的数组')
print(a.flatten()) # 默认按行展开，order:'C'--按行、'F'--按列、'A'--原顺序、'K'--元素在内存中的出现顺序
print('\n')

print('以 F 风格顺序展开的数组')
print(a.flatten(order='F'))
```
**输出结果**
```text
原数组
[[0 1 2 3]
 [4 5 6 7]]


展开的数组
[0 1 2 3 4 5 6 7]


以 F 风格顺序展开的数组
[0 4 1 5 2 6 3 7]
```
## 反转数组
### np.transpose()
>用于对换数组的维度
```python
import numpy as np
a=np.arange(8).reshape(2,4)
print('原数组')
print(a)
print('\n')

print('对换数组')
print(np.transpose(a))
print('\n')

#还有一种写法nparray.T效果和transpose类似
print(a.T)
```

```text

 [[0 4]

 ```
