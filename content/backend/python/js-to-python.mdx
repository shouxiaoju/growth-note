## 命名规范
- 第一个字符必须以字母（a-z, A-Z）或下划线
- 大小写敏感
- 禁止使用保留关键字，如 if、for、class 等不能作为标识符。
- Python 使用下划线分隔单词，如 snake_case或者使用驼峰命名法，如 camelCase

|特性|Python|
|:-------|:--------|
|普通变量/函数|camelCase (小驼峰命名法) or snake_case (蛇形命名法)|
|类名 (Class)|PascalCase (大驼峰)|
|常量 (Constant)|UPPER_SNAKE_CASE|

## 注释
**Python**
- 单行注释以 # 开头
- 多行字符串（由三个单引号 ''' 或三个双引号 """ 包围的文本块）可以用作多行注释。
```python
#这是一个注释
print("Hello, World!")
'''
这是多行注释，用三个单引号
这是多行注释，用三个单引号
这是多行注释，用三个单引号
'''
print("Hello, World!")

"""
这也是多行注释，用三个双引号
这也是多行注释，用三个双引号
这也是多行注释，用三个双引号
"""
#多行注释是由三个单引号 ''' 或三个双引号 """ 来定义的，这种注释方式不能嵌套使用。
```
> **注意:** 虽然多行字符串在这里被当作多行注释使用，但它实际上是一个字符串，我们只要不使用它，它不会影响程序的运行。
>这些字符串在代码中可以被放置在一些位置，而不引起实际的执行，从而达到注释的效果。

**Docstring 文档字符串**
Python 的 Docstring（文档字符串）是一种特殊的注释，用于为函数、类、模块等添加文档说明。与普通注释不同，Docstring 可以通过 __doc__ 属性直接访问，也可以使用 help() 函数查看。 
Docstring 使用三个双引号 """ 或三个单引号 ''' 包围，放在函数、类、模块的开头。
```python
def add(a, b):
    """返回两数之和"""
    return a + b

#通过 __doc__ 属性访问
print(add.__do c__)  # 输出: 返回两数之和

#使用 help() 函数
help(add)
'''Help on function add in module __main__:

add(a, b)
    返回两数之和
'''
```

## 数据类型转换
Python 中数据类型转换分为隐式转换（自动）和显式转换（手动，也叫类型转换/强制转换）。
### 隐式数据类型转换
Python 在运算时会自动把"小"类型转成"大"类型，避免精度丢失。
```python
num1 = 1 # int
num2 = 2.5 # float
num3 = num1 + num2
print(type(num3)) # <class 'float'>

#布尔值可以进行隐式转换
num4 = True
num5 = 10
num6 = num4 + num5
print(type(num6)) # <class 'int'>

```
>注意：隐式转换只发生在数值类型之间，"1" + 1 会直接报错。

### 显示转换
显示转换也叫强制转换，当python无法进行自动转换时，需要手动调用内置函数进行转换。

|函数|	作用|	示例|	结果
|--------|--------|--------|--------|
|int(x)|	转整数|	int("10")|	10
|float(x)|	转浮点数|	float("3.14")|	3.14
|str(x)|	转字符串|	str(123)|	"123"
|bool(x)|	转布尔|	bool(0)|	False
|list(x)	|转列表|	list("abc")|	['a','b','c']
|tuple(x)|	转元组|	tuple([1,2])|	(1, 2)
|set(x)|	转集合|	set([1,1,2])|	`{1, 2}`
|dict(x)|	转字典|	dict([("a",1)])|	`{'a': 1}`
|complex(x)|	转复数|	complex(2)|	(2+0j)

## 作用域
>Python 的作用域（scope）指的是一个变量名在程序中的有效范围——在哪些地方可以访问这个变量。理解作用域是避免“变量未定义”“修改不生效”这类问题的关键。

Python 查找变量时，按照 L → E → G → B 的顺序逐层查找：
|层级|	名称|	说明|
|:--------|:--------|:--------|
|L	|Local（局部）|	当前函数内部|
|E	|Enclosing（闭包）|	外层嵌套函数|
|G	|Global（全局）|	模块（文件）级别|
|B	|Built-in（内置）|	Python 内置命名空间|

```python
x = "global"          # G

def outer():
    x = "enclosing"   # E
    def inner():
        x = "local"   # L
        print(x)      # 先找 L → 找到 "local"
    inner()

outer()  # 输出: local
#如果 inner 里没有 x，就会往上一层找 enclosing，再没有就找 global，最后找内置。
```
### 全局作用域与局部作用域
>定义在函数内部的变量拥有一个局部作用域，定义在函数外的拥有全局作用域。  
局部变量只能在其被声明的函数内部访问，而全局变量可以在整个程序范围内访问。  
在函数内部声明的变量只在函数内部的作用域中有效，调用函数时，这些内部变量会被加入到函数内部的作用域中，并且不会影响到函数外部的同名变量

```python
x = 10          # 全局变量

def func():
    x = 20      # 这里是新的局部变量
    print(x)    # 20

func()
print(x)        # 10（全局的 x 没变）
```
**全局变量：** 在函数外部定义的变量，可以在整个文件中被访问。在函数外部定义的变量对所有函数都是可见的，除非函数内部定义了同名的局部变量。
```python
x = 10  # 全局变量

def my_function():
    print(x)  # 可以访问全局变量 x

my_function()  # 输出 10
```
**局部变量：** 在函数内部定义的变量，仅在函数内有效，函数外无法访问。局部变量优先级高于全局变量，因此如果局部变量和全局变量同名，函数内部会使用局部变量。
```python
def my_function():
    x = 5  # 局部变量
    print(x)  # 访问局部变量 x

my_function()  # 输出 5
print(x)  # 报错: NameError: name 'x' is not defined
```
**global 和 nonlocal关键字**

`global：`在函数内声明要修改的是全局变量。
```python
x = 10

def func():
    global x
    x = 20

func()
print(x)  # 20
```
`nonlocal：`在嵌套函数内声明要修改的是外层函数的变量（不是全局）。

```python
def outer():
    x = 10
    def inner():
        nonlocal x
        x = 20
    inner()
    print(x)  # 20

outer()
```
> **注意** nonlocal 只能用于嵌套函数中，且外层必须存在该变量，否则报 SyntaxError

### 常见陷阱
1. Python 的 if、for、while 不会创建新作用域：
    ```python
    for i in range(3):
        pass
    print(i)  # 2，i 在循环结束后依然存在
    ```
2. 闭包中的延迟绑定
    ```python
    funcs = []
    for i in range(3):
        funcs.append(lambda: i)

    print([f() for f in funcs])  # [2, 2, 2]，不是 [0, 1, 2]
    ```
    >因为 lambda 里的 i 是引用外层变量，循环结束时 i 已经是 2。要修复可以这样：
    ```python
    funcs = []
    for i in range(3):
        funcs.append(lambda i=i: i)  # 用默认参数绑定当前值

    print([f() for f in funcs])  # [0, 1, 2]
    ```
3. 类作用域不参与 LEGB 查找
    >类体是一个独立作用域，但方法内部不能直接访问类体里的变量：
    ```python
    class A:
    x = 10
    def method(self):
        print(x)   # NameError，不会去找类体的 x
        print(self.x)  # 正确，通过 self 访问
    ```

### 公有属性与私有属性
Python 没有像 Java/C++ 那样严格的访问修饰符（public/private/protected），而是通过命名约定来实现访问控制。

|命名方式|	类型|	说明
|:--------|:--------|:--------|
|name|	公有属性|	正常访问，外部可直接读写
|```_name```|	受保护属性|	约定俗成，提示"不要直接访问"（但语法上仍可访问）
|```__name```|	私有属性|	触发名称改写（name mangling），外部不易直接访问
|```__name__```|	魔术方法/属性|	Python 内置特殊成员，如 ```__init__```、```__dict__```

**公有属性:** 默认情况下，类中定义的属性都是公有的，任何地方都能访问和修改。
```python
class Person:
    def __init__(self, name, age):
        self.name = name    # 公有属性
        self.age = age      # 公有属性

p = Person("张三", 25)
print(p.name)   # 张三
print(p.age)    # 25

p.age = 30      # 外部可以直接修改
print(p.age)    # 30
```
**受保护属性:** 以单个下划线开头，是一种约定，表示"这是内部使用的，请不要随意访问",但语法上仍可以正常访问，只是社区约定不推荐。
```python
class Person:
    def __init__(self, name, salary):
        self.name = name
        self._salary = salary    # 受保护属性

p = Person("张三", 10000)
print(p._salary)   # 10000，语法上可以访问，但不推荐
p._salary = 20000  # 也可以修改

#约定：_name 是给子类和内部使用的，外部应尽量避免直接访问。
```

**私有属性:** 以双下划线开头、且不以双下划线结尾的属性.。

Python 会把 ```__name``` 改写成 ```_类名__name```，从而达到"私有"效果。
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.__age = age      # 私有属性

    def get_age(self):
        return self.__age

    def set_age(self, age):
        if age > 0:
            self.__age = age


p = Person("张三", 25)

print(p.name)          # 张三（公有，正常访问）
print(p.get_age())     # 25（通过公有方法访问私有属性）

#print(p.__age)       # ❌ AttributeError: 'Person' object has no attribute '__age'
#p.__age = 30         # 这只是新增了一个公有属性，不影响私有属性

print(p._Person__age)  # 25 —— 名称改写后仍可访问（但不推荐）
```

class Circle:
    def __init__(self, radius):
        self._radius = radius
    @property                          # getter
    def radius(self):

    @radius.setter                     # setter

## Python中的文件读写open() 方法
open() 方法用于打开一个文件，并返回文件对象。

```open(file, mode='r')```

完整入参及参数说明

```open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)```

参数说明:
- file: 必需，文件路径（相对或者绝对路径）。
- mode: 可选，文件打开模式
- buffering: 设置缓冲
- encoding: 一般使用utf8
- errors: 报错级别
- newline: 区分换行符
- closefd: 传入的file参数类型
- opener: 设置自定义开启器，开启器的返回值必须是一个打开的文件描述符。

```python

    f.write("hello")
#逐行读（大文件推荐）
with open("data.txt") as f:
    for line in f:      # 直接迭代文件对象！
        print(line.strip()) 
```

### with 关键字
with 是 Python 中的一个关键字，用于上下文管理协议。它简化了资源管理代码，特别是那些需要明确释放或清理的资源（如文件、网络连接、数据库连接等）。

#### 为什么需要 with 关键字
传统文件操作
```python
file = open('example.txt', 'r')
try:
    content = file.read()
    # 处理文件内容
finally:
    file.close()
```
这种写法存在几个问题：
- 容易忘记关闭资源：如果没有 try-finally 块，可能会忘记调用 close()
- 代码冗长：简单的文件操作需要多行代码
- 异常处理复杂：需要手动处理可能出现的异常
- 
with 语句的优势
- 自动资源释放：确保资源在使用后被正确关闭
- 代码简洁：减少样板代码
- 异常安全：即使在代码块中发生异常，资源也会被正确释放
- 可读性强：明确标识资源的作用域

with 语句的基本形式如下：
```python
'''
with expression [as variable]:
    # 代码块
expression 返回一个支持上下文管理协议的对象
as variable 是可选的，用于将表达式结果赋值给变量
代码块执行完毕后，自动调用清理方法
'''
with open('example.txt', 'r') as file:
    content = file.read()
    print(content)
#文件已自动关闭
```

## Python中的模块

### 什么是模块

在Python中一个.py文件就是一个模块。
  - 定义：任何包含 Python 代码的文件（以 .py 结尾），都可以被视为一个模块。
  - 命名规则：模块名通常与文件名一致（例如 math.py 对应的模块名是 math）。
  - 作用域：模块内部定义的变量函数、类，默认都是该模块的“私有”或“公共”成员，外部通过导入机制访问。

```python
#example.py (这就是一个模块)
def greet(name):
    return f"Hello, {name}!"

PI = 3.14159

class Calculator:
    def add(self, a, b):
        return a + b
```
在python中不像其他语言一样需要导出模块外面才可以导入，python中模块是默认导出的其他模块可以通过import导入使用，但在开发过程中通常有几种通用的标准做法。
1. 使用 ```__all__ ```列表（最通用）
   - 这是 Python 官方推荐的标准做法，适用于所有版本。它定义了当用户使用 from module import * 时应该导入的内容，同时也作为文档说明该模块的公共 API。
       ```python
       def _private_helper():  # 前缀下划线表示私有
            pass

       def public_function():
            pass

       class PublicClass:
            pass

        # ✅ 定义公共 API
        __all__ = ['public_function', 'PublicClass']
        #  from mylib.core import * 只会导入 public_function 和 PublicClass。
        ```
2. 基于命名约定的隐式导出（现代最佳实践）
   - 依靠严格的命名约定来自动区分公共和私有内容。这种方式更简洁，减少了维护成本。
   ```python
    # 公共（Public）：不以 _ 开头的名称。
    # 私有（Private）：以 _ 开头的名称。
    def helper():       # ✅ 公共函数
        pass

    def _internal_log(): # ❌ 私有函数，外部不应直接调用
        pass

    class Model:         # ✅ 公共类
        pass

    class _BaseModel:    # ❌ 私有基类
        pass
    ```
    > 如果你选择这种方式，必须在项目规范中明确规定“所有非 _ 开头的名称均为公共 API”，并在 CI/CD 中通过 linting 工具（如 flake8, ruff）进行检查。
3. 动态懒加载导出（性能优化）
    -对于大型库（如 numpy, pandas, tensorflow），一次性导入所有子模块会导致启动缓慢。利用 ```__getattr__``` 实现按需导出成为高性能库的标准模式。
    ```python
    # mylib/__init__.py

    import sys
    from typing import TYPE_CHECKING

    if TYPE_CHECKING:
        # 仅在类型检查时导入，避免运行时开销
        from .heavy_module import HeavyEngine
        from .io import read_csv

    def __getattr__(name):
        """
        当用户尝试访问未直接定义的属性时触发。
        实现“懒加载”导出。
        """
        if name == "HeavyEngine":
            from .heavy_module import HeavyEngine
            return HeavyEngine
        elif name == "read_csv":
            from .io import read_csv
            return read_csv
    
        raise AttributeError(f"module '{__name__}' has no attribute '{name}'")

    def __dir__():
        """
        让 dir() 命令也能看到这些动态属性，方便用户探索 API。
        """
        items = ["HeavyEngine", "read_csv"]
        items.extend(globals().keys())
        return items
    ```

Python 提供了多种导入方式，选择合适的方式能保持代码整洁并避免命名冲突。

1. 基本导入语法
```python
#场景1：导入整个模块
import math
print(math.sqrt(16))  # 输出: 4.0

#场景2：从模块中导入特定对象
from math import sqrt, pi
print(sqrt(16))       # 输出: 4.0
print(pi)             # 输出: 3.14159...

#场景3：使用别名（Alias）
import numpy as np
import pandas as pd

#场景4：导入所有（不推荐，除非明确知道自己在做什么）
from os import *
```
2. 绝对导入 vs 相对导入（在包结构中）

目录解构
```text
my_project/
├── main.py
└── utils/
    ├── __init__.py
    ├── helpers.py   # 这里要用到 math_module
    └── math_module.py
```
```python
#绝对导入（推荐，清晰明了）
#utils/helpers.py
import my_project.utils.math_module  # 完整路径
#或者如果当前目录已在 sys.path 中：
import utils.math_module

#相对导入（适用于包内部） 使用 . 表示当前包，.. 表示父包。
#utils/helpers.py
from . import math_module      # 导入同级模块
from ..core import engine      # 导入父包的 core 模块
```
>**注意：** 相对导入只能在作为包的一部分被导入时使用。如果你直接运行 python utils/helpers.py，相对导入会报错

**```__name__```** 变量

这是 Python 模块最独特的特性之一：模块既可以被导入，也可以被直接运行。

每个模块都有一个内置变量__name__：
- 当模块被直接运行时（如 python my_script.py），```__name__ ```的值为 '```__main__```'。
- 当模块被其他模块导入时，```__name__``` 的值为模块的文件名（不含 .py）。

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

#这段代码只有在直接运行本文件时才会执行
if __name__ == '__main__':
    print("正在直接运行计算器模块")
    print(f"2 + 3 = {add(2, 3)}")
    
    # 这里可以写单元测试代码
    assert add(2, 3) == 5
    print("测试通过！")
else:
    print("本模块被导入，跳过执行测试代码")
```

## Python 中的包（Packages）
在 Python 中，包（Package） 是一个包含多个模块（Module）的目录，在旧版本中它通过 ```__init__.py``` 文件来标识自己是一个包。包允许我们将相关的代码组织在一起，便于管理和复用。
Python 3.3+ 支持无 ```__init__.py ```的命名空间包，但在绝大多数商业项目、库开发和框架中，显式的 ```__init__.py``` 仍然是最佳实践。

```text
my_package/
├── __init__.py      # 标识这是一个包，可包含初始化代码
├── module_a.py      # 子模块 A
├── module_b.py      # 子模块 B
└── subpackage/
    ├── __init__.py
    └── module_c.py   # 子包中的模块

```
**```__init\\__.py```** 的作用
```python
#mylib/__init__.py

#方式1：显式导入子模块
from .utils import greet, add
from .helpers import do_something

#方式2：控制暴露的 API（推荐）
__all__ = ['greet', 'add', 'do_something']

#方式3：自动发现并导入所有子模块（Python 3.3+ 支持隐式命名空间包，但通常仍需 __init__.py）
import pkgutil
import sys

def _load_submodules(package, pattern):
    """动态加载子模块"""
    fullname = package.__name__
    for importer, modname, ispkg in pkgutil.iter_modules(
        package.__path__, fullname + "."
    ):
        if not pattern or pattern.search(modname):
            module = __import__(modname, fromlist=[''])
            setattr(package, modname.split('.')[-1], module)
```
**使用包**
```python
#方式1：导入整个包
import mylib
mylib.greet("Alice")

#方式2：从包中导入特定内容
from mylib import greet, add
print(greet("Bob"))
print(add(1, 2))

#方式3：导入子模块
from mylib.helpers import do_something
do_something()

#方式4：别名导入
from mylib.utils import greet as say_hello
say_hello("Charlie")
```

## json格式化数据
### Python 对象 → JSON 字符串（序列化）
```python
import json

data = {
    "name": "张三",
    "age": 25,
    "city": "北京",
    "hobbies": ["读书", "游泳"],
    "is_student": False,
    "score": None
}

#转换为 JSON 字符串
json_str = json.dumps(data, ensure_ascii=False)
print(json_str)
#{"name": "张三", "age": 25, "city": "北京", "hobbies": ["读书", "游泳"], "is_student": false, "score": null}
```
**常用参数：**

|参数|	说明
|:--------|:--------|
|ensure_ascii=False|	保留中文，不转成 \uXXXX
|indent=4|	缩进格式化输出
|sort_keys=True|	按键排序
|separators=(',', ':')|	自定义分隔符

### JSON 字符串 → Python 对象（反序列化）
```python
json_str = '{"name": "张三", "age": 25, "hobbies": ["读书", "游泳"]}'

data = json.loads(json_str)
print(data["name"])      # 张三
print(data["hobbies"][0]) # 读书
print(type(data))         # <class 'dict'>
```

### 读写 JSON 文件
```python
#写入文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=4)

#读取文件
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```
>注意：dumps/loads 处理字符串，dump/load 处理文件对象。


## 避坑指南 —— JS 开发者最常踩的 10 个坑
1. 缩进是语法：混用 Tab 和空格报 IndentationError，统一用 4 空格
2. **没有 ++/--**：i++ 是语法错误，用 i += 1
3. 字典没有点语法：obj.name 报错，必须 obj["name"]
4. **True/False/None 大写**：小写报 NameError
5. **and/or/not**：不能用 &&/||/!
6. **elif 不是 else if**：一个词，中间没空格
7. **range 不含终点**：range(5) 是 0-4，和 for(i=0;i< 5;i++) 一致
8. **整除用 //**：7/2 是 3.5，7//2 才是 3
9. **self 必须显式写**：类方法第一个参数永远是 self
10. **asyncio.run() 别忘**：async 函数不会自动执行
