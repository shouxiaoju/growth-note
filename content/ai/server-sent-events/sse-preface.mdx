### 第二部: Fetch + ReadableStream 手动解析
在 React 项目中，fetch + ReadableStream 是实现流式输出的核心底层技术
```
浏览器 ←→ 服务器
   │          │
   │  1. fetch POST /api/chat
   │  2. 服务器返回 ReadableStream (Transfer-Encoding: chunked)
   │  3. 浏览器通过 response.body.getReader() 逐块读取
   │  4. 每读取一块，更新 React 状态 → UI 实时渲染
   └──────────┘
```
